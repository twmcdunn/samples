# samples
Sound samples used by my other repos.

The audio files are not stored in this repository. They are published only as a
release asset named `samples.zip` attached to the latest release.

## Download
The latest samples are always available at:

```
https://github.com/twmcdunn/samples/releases/latest/download/samples.zip
```

For example:

```sh
curl -L -o samples.zip https://github.com/twmcdunn/samples/releases/latest/download/samples.zip
unzip samples.zip
```

## Releases
Every release must:
- attach a single asset named exactly `samples.zip`
- keep the same file structure as the previous release, plus any new sounds
